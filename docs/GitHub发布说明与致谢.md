# 易用TV助手 · 发布说明与致谢

仓库：<https://github.com/pangtugg/easytv-partner>　作者：胖兔（抖音 8700251）

## 关于

给电视和电视盒子的工具箱，九个模块：扫码遥控、投屏、传文件、装应用、订阅推送、应用更新、工具箱、设置、关于。电视手机同一个包，安卓 5.0 以上，32/64 位通吃。

不弹广告，不偷传数据，不注册账号，不联网的功能照样能用。

## 致谢

以下项目只借鉴思路，未使用其代码：

- **Clean Your TV**（@udhaykumarbala / 原版 @Gathin23）——垃圾清理的做法：扫出来、按大小排、用户自己决定删哪个
- **tv-detox**（@Ansub）——电视桌面做减法，能砍就砍
- **Clash Meta for Android**（@MetaCubeX）——订阅一键导入
- **红果短剧 / 抖音TV 社区**（@aston314、@jackherex、@mytv-android、@markwaveio、@ygtec-org）——电视端遥控交互
- **BT**（@chinasoul）——电视端焦点与播放
