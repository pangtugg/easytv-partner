# 易用TV助手 · 使用帮助

电视 / 盒子上打开助手，首页就是下面六个大方块。想知道哪个功能在哪，照入口找就行；遥控器选中一个按确定就进去。

## 首页六个入口

| 入口 | 点进去是什么 | 里面有什么 |
|------|--------------|------------|
| 扫码遥控 | 打开手机遥控页，电视上出二维码 | 用手机扫码当遥控器，打字、点按 |
| 投屏 | 电视端进相册；手机端进发送页 | 把手机照片 / 视频投到电视看 |
| 传文件 | 先选方向，再进对应收发页 | 电视与手机互传文件、安装包、文字 |
| 工具箱 | 进入工具箱，里面还有 5 个子功能 | 设备信息、垃圾清理、推送助手、易用桌面（仅电视）、应用管理 |
| 设置 | 进入设置页 | 设备、网络、文件、应用四组设置 |
| 关于 | 进入关于页 | 版本、检查更新、运行自检、作者主页 |

> 「推送助手」「应用推荐 / 应用更新」「系统清理」「易用桌面」这些，都在「工具箱」里面，首页不用到处找。

## 扫码遥控

**入口**：首页 → 扫码遥控（仅电视 / 盒子端有这一格，手机端没有）

**干嘛用**：电视上显示一个二维码，用手机扫一下，就能像遥控器一样在手机上操作电视——打字、点按都行。

**怎么用**：
1. 在电视 / 盒子的首页，选中「扫码遥控」，按确定。
2. 电视屏幕上会出现一个二维码。
3. 用手机相机或微信「扫一扫」扫描这个二维码，手机会打开网页遥控器。
4. 在手机上点方向、按确认、输入文字，电视会实时跟着动。

**支持**：手机和电视连同一个 Wi-Fi 就能用；手机浏览器扫码即用，不用额外装 App。

**不支持 / 注意**：手机和电视不在同一个网络时用不了；手机端 App 里没有这一格。

> 小提示：电视遥控器打字最费劲，搜索、填地址时用这个在手机上打字最快。

## 投屏

**入口**：首页 → 投屏

**干嘛用**：把手机相册里的照片、视频投到电视大屏上看，手机上选、电视上看。

**怎么用**：
1. 电视端：第一次点「投屏」会先自动测一下这台机子能扛多大的照片和视频，测完进入相册页。
2. 手机端：点「投屏」进入发送页，从相册里挑要投的照片或视频。
3. 选好点发送，电视端会以九宫格展示，点任意一张切到全屏，可以左右翻着看。

**支持**：照片、视频都能投；手机和电视连同一个 Wi-Fi 即可。

**不支持 / 注意**：不做手机屏幕的实时镜像——这里只把照片 / 视频文件传过去在大屏上浏览，不是边玩手机边同步画面。

> 小提示：第一次用电视端点「投屏」会先自检硬件，属正常，之后不再重复测。

## 传文件

**入口**：首页 → 传文件

**干嘛用**：电视和手机之间互传文件、安装包、文字，不用数据线。

**怎么用**：
1. 首页点「传文件」，先选一个方向：「手机 → 电视（收文件）」或「电视 → 手机（给手机东西）」。
2. 手机 → 电视：在手机端选好文件点发送，电视端会自动接收并列出。
3. 电视 → 手机：电视端出一个取件二维码，手机扫码就能把文件拿走。
4. 传完的文件都在「接收列表」里能看到。

**支持**：任意文件、安装包(.apk)、以及一小段文字；手机和电视连同一个 Wi-Fi 即可。

**不支持 / 注意**：跨网络（不同 Wi-Fi、走外网）传不了，必须在同一个局域网里。

> 小提示：想给电视装应用但手上没有安装包：用「电视 → 手机」把电视里的包拿到手机，反过来也能把手机的包推给电视。

## 工具箱

**入口**：首页 → 工具箱（手机端没有「易用桌面」这一格）

**干嘛用**：偶尔才用一次的工具都归在这里：看设备信息、清垃圾、管推送、换桌面、装应用和更新。

**怎么用**：
1. 首页点「工具箱」，进来是一个小宫格。
2. 按需点进去：设备信息 / 垃圾清理 / 推送助手 / 易用桌面（仅电视）/ 应用管理。
3. 每个子功能进去后按屏幕提示操作，返回键退回工具箱。

### 设备信息
看这台机子的型号、内存、存储，以及投屏能力；投屏测过想重测，也在这里。

### 垃圾清理
扫出闲置的安装包、空文件夹，勾选后一键清掉，腾空间、少卡顿。

### 推送助手
分两件事：订阅推送管订阅链接，源推送把源推给播放器。

- 怎么用：
  1. 工具箱点「推送助手」，里面是「订阅推送」和「源推送」两个模块。
  2. 点「源推送」，两个入口各管一类：「MYTV 一键推源」只推直播源，「其他端一键推源」只推影视源。
  3. 点其中一个，会先弹出说明告诉你这次推哪一类，按「确定」才开始推。
  4. 这条源如果已经推过，会再问一次「是否覆盖推送」；点取消就不动已有的源。
  5. 直播和影视都要，就把两个入口各点一次；一次不会同时推两类。
  6. 点「订阅推送」，添加订阅链接，再点页面底部的「订阅推送」推给客户端。
  7. 个别推不过去的，会列出地址让你复制一次，粘到播放器里即可。
- 支持：MYTV 系列与常见影视壳；Clash 等代理客户端。
- 不支持 / 注意：
  - 没装「我的电视」时推不了直播源；没装影视壳时推不了影视源，屏幕会直接说明。
  - 播放器里自己手工加的源查不到，只有「本工具推过这条源」时才会问是否覆盖。

### 易用桌面（仅电视 / 盒子端）
把电视原厂桌面换成大字大图标的易用桌面，遥控器好按、占用低；随时一键还原。

- 怎么用：
  1. 在工具箱里点「易用桌面」进入，开启并设为默认桌面。
  2. 回到电视主页，就是新的大字桌面。
  3. 想换回原厂，回到这里点还原即可。
- 支持：仅电视 / 盒子端提供；占用极低，老盒子换了明显更顺。
- 不支持 / 注意：手机上不铺这一格。

### 应用管理
装应用 / 应用更新 / 删除应用 三合一：从推荐清单或本地包装应用、给已装应用查更新、卸掉不用的。

- 怎么用：
  1. 点「应用管理」，按分类浏览或找已装应用。
  2. 装应用：选中应用点安装，助手自动下载并装上。
  3. 应用更新：切到更新页，按右键选「忽略更新」或「更新」。
  4. 点「忽略更新」后二选一：本次忽略（下次检查还会提示）/ 永久忽略（左栏「已忽略」可恢复）。
  5. 删除应用：在列表里选中不用的，点卸载。
- 支持：推荐清单里的应用、本地 apk 安装、已装应用查更新与卸载。
- 不支持 / 注意：部分电视 / 盒子需先在系统里允许「安装未知来源应用」，否则装不上。

## 设置

**入口**：首页 → 设置

**干嘛用**：只放「能改的东西」：设备昵称、网络出口、接收目录、自动安装、极简主页，一页说清。

**怎么用**：
1. 首页点「设置」，从上到下是四组：设备、网络、文件、应用。
2. 设备：改设备昵称（电视端点这一行，用手机扫码输入）；切换端类型（自动 / 电视 / 手机）。
3. 网络：选网络出口（跟随系统 / 自定义代理），填代理地址；改乱了可一键还原成跟随系统。
4. 文件：改接收目录（收到的文件存到手机的「下载」里哪个文件夹）；看网页管理地址与二维码。
5. 应用：开关自动安装、常驻可被发现、极简主页。

**支持**：昵称、网络出口、代理地址、接收目录、自动安装、极简主页都能在这里改。

**不支持 / 注意**：电视上直接敲一长串地址不方便——要打字的地方一律走「扫码在手机上填」。

> 小提示：网络出口默认「跟随系统」就对；要挂代理时才切「自定义代理」并填 host:port。

## 关于

**入口**：首页 → 关于

**干嘛用**：看版本号、构建戳，检查更新，运行一次自检，以及作者和主页地址。

**怎么用**：
1. 首页点「关于」，最上面是版本号 + 构建戳。
2. 点「检查更新」：有新版本会提示，点更新自动下载安装；没有会提示已是最新。
3. 点「运行自检」：一次性看版本、出口线路、镜像清单、安装权限、远程配置是否正常。
4. 下面还有作者主页地址与抖音号。

**支持**：检查更新、运行自检、查看版本与构建戳。

**不支持 / 注意**：版本信息以「关于」页为准，别处看到的仅供参考。

> 小提示：出问题时先来「关于 → 运行自检」，很多情况一眼就能看出是哪一环不对。
