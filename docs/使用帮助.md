# 易用TV助手 · 使用帮助

电视 / 盒子上打开助手，首页就是下面六个大方块。想知道哪个功能在哪，照入口找就行；遥控器选中一个按确定就进去。

## 首页六个入口

| 入口 | 点进去是什么 | 里面有什么 |
|------|--------------|------------|
| 扫码遥控 | 打开手机遥控页，电视上出二维码 | 用手机扫码当遥控器，打字、点按 |
| 投屏 | 电视端进相册；手机端进发送页 | 把手机照片 / 视频投到电视看 |
| 传文件 | 先选方向，再进对应收发页 | 电视与手机互传文件、安装包、文字 |
| 工具箱 | 进入工具箱，里面是 4 个大卡片 | 应用管理、推送助手、易用桌面（仅电视）、垃圾清理 |
| 设置 | 四张大卡片，点进去才是具体内容 | 设备信息、基本设置、性能测试、运行自检 |
| 关于 | 进入关于页 | 抖音码、联系方式、官网与项目地址、检查更新 |

> 「推送助手」「应用管理」「垃圾清理」「易用桌面」都在「工具箱」；「设备信息」「性能测试」「运行自检」都在「设置」里。

## 扫码遥控

**入口**：首页 → 扫码遥控（仅电视 / 盒子端有这一格，手机端没有）

**干嘛用**：电视上显示一个二维码，用手机扫一下，就能像遥控器一样在手机上操作电视——打字、点按都行。

**怎么用**：
1. 在电视 / 盒子的首页，选中「扫码遥控」，按确定。
2. 电视屏幕上会出现一个二维码。
3. 用手机相机或微信「扫一扫」扫描这个二维码，手机会打开网页遥控器。
4. 在手机上点方向、按确认、输入文字，电视会实时跟着动。

**支持**：手机和电视连同一个 Wi-Fi 就能用；手机浏览器扫码即用，不用额外装 App。

**不支持 / 注意**：手机和电视不在同一个网络时用不了；手机端 App 里没有这一格。

> 小提示：电视遥控器打字最费劲，搜索、填地址时用这个在手机上打字最快。

## 投屏

**入口**：首页 → 投屏

**干嘛用**：把手机相册里的照片、视频投到电视大屏上看，手机上选、电视上看。

**怎么用**：
1. 电视端：第一次点「投屏」会先自动测一下这台机子能扛多大的照片和视频，测完进入相册页。
2. 手机端：点「投屏」进入发送页，从相册里挑要投的照片或视频。
3. 选好点发送，电视端会以九宫格展示，点任意一张切到全屏，可以左右翻着看。

**支持**：照片、视频都能投；手机和电视连同一个 Wi-Fi 即可。

**不支持 / 注意**：不做手机屏幕的实时镜像——这里只把照片 / 视频文件传过去在大屏上浏览，不是边玩手机边同步画面。

> 小提示：第一次用电视端点「投屏」会先自检硬件，属正常，之后不再重复测。

## 传文件

**入口**：首页 → 传文件

**干嘛用**：电视和手机之间互传文件、安装包、文字，不用数据线。

**怎么用**：
1. 首页点「传文件」，先选一个方向：「手机 → 电视（收文件）」或「电视 → 手机（给手机东西）」。
2. 手机 → 电视：在手机端选好文件点发送，电视端会自动接收并列出。
3. 电视 → 手机：电视端出一个取件二维码，手机扫码就能把文件拿走。
4. 传完的文件都在「接收列表」里能看到。

**支持**：任意文件、安装包(.apk)、以及一小段文字；手机和电视连同一个 Wi-Fi 即可。

**不支持 / 注意**：跨网络（不同 Wi-Fi、走外网）传不了，必须在同一个局域网里。

> 小提示：想给电视装应用但手上没有安装包：用「电视 → 手机」把电视里的包拿到手机，反过来也能把手机的包推给电视。

## 工具箱

**入口**：首页 → 工具箱（手机端没有「易用桌面」这一格）

**干嘛用**：偶尔才用一次的工具都归在这里：清垃圾、管推送、换桌面、装应用和更新。想看设备信息、测性能，去「设置」。

**怎么用**：
1. 首页点「工具箱」，进来是四张大卡片，铺满整屏。
2. 按需点进去：应用管理 / 推送助手 / 易用桌面（仅电视）/ 垃圾清理。
3. 每个功能进去后按屏幕提示操作，返回键退回工具箱。

**支持**：垃圾清理、推送助手、应用管理在电视和手机端都有。

**不支持 / 注意**：「易用桌面」只在电视 / 盒子端出现；「设备信息」已挪到「设置」，工具箱里不再有。

### 垃圾清理
扫出闲置的安装包、临时文件和空文件夹。进页面自动扫一遍，默认全部勾上，点「一键清理」就清掉，腾空间、少卡顿。

- 扫不到东西时，点「授权文件夹」把下载目录这些位置交给它读，再点「重新扫描」。
- 列表里会写明这个包电视上装的是哪一版、旧了几个版本，判断能不能删。

### 推送助手
分两件事：订阅推送管订阅链接，源推送把源推给播放器。

- 怎么用：
  1. 工具箱点「推送助手」，里面是「订阅推送」和「源推送」两个模块。
  2. 点「源推送」，两个入口各管一类：「MYTV 一键推源」只推直播源，「其他端一键推源」只推影视源。
  3. 点其中一个，会先弹出说明告诉你这次推哪一类，按「确定」才开始推。
  4. 这条源如果已经推过，会再问一次「是否覆盖推送」；点取消就不动已有的源。
  5. 直播和影视都要，就把两个入口各点一次；一次不会同时推两类。
  6. 点「订阅推送」，添加订阅链接，再点页面底部的「订阅推送」推给客户端。
  7. 个别推不过去的，会列出地址让你复制一次，粘到播放器里即可。
- 支持：MYTV 系列与常见影视壳；Clash 等代理客户端。
- 不支持 / 注意：
  - 没装「我的电视」时推不了直播源；没装影视壳时推不了影视源，屏幕会直接说明。
  - 播放器里自己手工加的源查不到，只有「本工具推过这条源」时才会问是否覆盖。

### 易用桌面（仅电视 / 盒子端）
把电视原厂桌面换成大字大图标的易用桌面，遥控器好按、占用低；随时一键还原。

- 怎么用：
  1. 在工具箱里点「易用桌面」进入，开启并设为默认桌面。
  2. 回到电视主页，就是新的大字桌面。
  3. 想换回原厂，回到这里点还原即可。
- 支持：仅电视 / 盒子端提供；占用极低，老盒子换了明显更顺。
- 不支持 / 注意：手机上不铺这一格。

### 应用管理
装应用 / 应用更新 / 删除应用 三合一：从推荐清单或本地包装应用、给已装应用查更新、卸掉不用的。

- 怎么用：
  1. 点「应用管理」，按分类浏览或找已装应用。
  2. 装应用：选中应用点安装，助手自动下载并装上。
  3. 应用更新：切到更新页，按右键选「忽略更新」或「更新」。
  4. 点「忽略更新」后二选一：本次忽略（下次检查还会提示）/ 永久忽略（左栏「已忽略」可恢复）。
  5. 删除应用：在列表里选中不用的，点卸载。
- 支持：推荐清单里的应用、本地 apk 安装、已装应用查更新与卸载。
- 不支持 / 注意：部分电视 / 盒子需先在系统里允许「安装未知来源应用」，否则装不上。

## 设置

**入口**：首页 → 设置

**干嘛用**：进来先看四个大模块：设备信息、基本设置、性能测试、运行自检。点一张进去，才是具体读数或开关。

**怎么用**：
1. 首页点「设置」，进来是四张大卡片：设备信息 / 基本设置 / 性能测试 / 运行自检。
2. 点「设备信息」看详细读数，顶部可以改设备昵称。
3. 点「基本设置」改网络、接收目录、自动安装这些开关。
4. 点「性能测试」一次测完设备情况、播放能力、照片打开。
5. 点「运行自检」看版本、网络线路、镜像清单、安装权限、远程配置是否正常。

**支持**：设备昵称、网络出口、代理地址、接收目录、自动安装都能改；设备信息只读查看；播放能力跟着性能测试一次测完；运行自检只读不改。

**不支持 / 注意**：电视上直接敲一长串地址不方便——代理地址一律走「扫码在手机上填」；播放能力不再单独列一个模块，也不在设备信息里重复出现。

> 小提示：网络出口默认「跟随系统」就对；要挂代理时才切「自定义代理」。

### 设备信息
只读展示这台机子：设备昵称、形态与身份、系统与硬件、内存、存储、屏幕、电量、网络。点最上面「设备昵称」可以改名。

### 基本设置
要改的都在这儿：网络出口（跟随系统 / 直连 / 自定义代理）、代理地址、接收目录、APK 自动安装、网页管理地址。

- 网络出口默认「跟随系统」；要挂代理才切「自定义代理」，地址用手机扫码填。
- 改乱了点「恢复默认：跟随系统网络」即可。

### 性能测试
一整块检测卡，点一次就全测完，结果直接给结论：这台机器在电视盒子芯片天梯里排第几名、打败全国多少台电视和盒子、属于高性能还是中性能，接着是能不能硬解 4K、支持哪些格式、最高到多少分辨率。测过之后按钮变成「重新检测」，想再测点一次即可。

### 运行自检
一次性看版本、网络线路（直连还是备用镜像）、镜像清单、安装权限、远程配置是否正常。出问题先来这儿，哪一环不对一眼就看得出来。

## 关于

**入口**：首页 → 关于

**干嘛用**：看作者是谁、怎么找过来，以及检查更新。

**怎么用**：
1. 首页点「关于」，最上面是抖音二维码和出品方，抖音号就写在「胖兔 出品」后面。手机抖音扫这个码，能找到作者主页、加入反馈交流群。
2. 中间一张卡：上面三句话是作者想说的，下面两行是「官网地址」和「项目地址」，右边还挂着一个官网二维码，扫它直接开官网。整张卡按一下会把官网地址复制走，提示「已复制官网地址，去浏览器打开吧」，粘到手机或电脑的浏览器就能打开。
3. 最下面一条「检查更新」：右边写着当前版本号和构建戳。点一下检查，有新版本会弹窗，按提示更新即可；没有就提示一句「已经是最新版本」。

**支持**：扫码找作者 / 进群、复制官网地址、检查更新、查看版本与构建戳。

**不支持 / 注意**：不在电视上直接打开网页——电视自带浏览器排版乱、遥控器也不好操作，所以这里只帮你把地址复制走。

> 小提示：出问题时先去「设置 → 运行自检」，很多情况一眼就能看出是哪一环不对。
