# 易用TV助手

> 作者：胖兔（抖音 8700251）｜源码：https://github.com/pangtugg/easytv-partner

---

## 这是什么

易用TV助手是一个给**智能电视和电视盒子**用的工具应用。手机电视互传文件、
投照片视频、清理电视垃圾、推送订阅、检查应用更新——全部按遥控器和大字做，
目标是让不擅长折腾电子设备的人也能自己用明白。

**它不是「老人专用」**。每个人都能用，只是对不擅长折腾的人更友好。
适老改良的意思不是把东西做旧、做笨，而是**把复杂留给自己，把简单留给用户**。

---

## 为什么做这个

给电视装个应用，得先把网址抄到手机上再传过去；想把手机里的照片弄到电视上，
得先学一遍「无线投屏」；软件更新了不会点，还怕点到广告。

我想做的就是**做一个最好用、最简单的电视助手，最适合中国人家的使用习惯，
也做得适老化** —— 不是把东西做旧、做笨，而是**把复杂留给自己，把简单留给用户**。

具体落到做法上就是几条：

- **一个功能只在一处出现**，首页一键直达，不搞「传文件 → 选方向 → 再选功能」这种套娃。
- **模块宁缺毋滥**，砍掉的那些都是可有可无的，留在那儿只会让人找不着北。
- **做减法比做加法难**。难做的地方不是加功能，是忍住不加。

## 装在什么上

**一个包，电视手机都能装，不用自己挑版本。**

- **安卓 5.0 到 14 都能装**（家里那台老电视、盒子上的旧安卓，一样能跑）
- **32 位 64 位通吃**，不用担心芯片是 64 位系统却是 32 位的情况
- **装完自动认设备**：手机上装就竖屏、手机界面；电视和盒子上装就横屏、遥控器界面。
  首页标题那行会写明现在是「手机端」还是「电视/盒子端」，一眼就清楚，不用自己找地方切

手机上主要用来扫码、传文件、投屏、装应用；电视上主要用传文件、清理垃圾、投屏。
两边是同一个 App，不用装两个。

## 做了哪些功能

首页九个宫格，电视端 3×3 对称，一屏放得下不用翻页。

| 模块 | 干什么 |
|---|---|
| **扫码遥控** | 电视上出二维码，手机扫一下就能在手机上点，电视跟着动。不想用遥控器也行 |
| **投屏** | 手机里的照片视频推上电视看，不用学「无线投屏」那一套 |
| **传文件** | 电视和手机互相收发，APK、照片、文本都行，断了能接着传 |
| **装应用** | 贴一个网址，电视自己下载、自己装好——电视没有浏览器也能装 |
| **订阅助手** | 订阅链接一键推给电视上的 Clash，保留自动更新 |
| **应用更新** | 扫已装应用比对版本；还能一键装推荐的开源应用；也能查助手自己的新版本 |
| **工具箱** | 垃圾清理、应用卸载、设备信息、网络诊断 |
| **设置** | 网络代理（默认永远跟随系统）、文件位置、开关 |
| **关于** | 版本、作者、反馈二维码 |

### 几个我自己比较满意的地方

- **字大、看得清**：正文用的是大字号，电视上一两米外能看清。
  遥控器移到哪儿，那儿就高亮起来，不会「不知道停在哪一行」。
- **推荐应用逐字节核对**：收录的每个包都核对作者公布的 SHA-256，
  对不上宁可删掉不装——下载走中转站，链路多一环就多一分被动手脚的可能。
- **不联网也能用**：清理、文件管理、电视输入法这些都不需要网络。
- **出错不装死**：连不上、下载失败、权限没开，都有中文提示说清楚下一步该干什么。
- **清理有安全红线**：系统目录、已装应用本体一律不碰；
  删不掉的文件会告诉你原因，不会假装删了。
- **网络默认永远跟随系统**：想改成直连或自定义也能改，但默认值就是跟随。

## 模块是怎么布局的

**首页**：九个宫格，电视端 3 列 3 行，手机端 2 列往下排。
一屏之内能看完所有功能，不用翻页、不用找菜单。

**应用更新页**：左边一条竖栏放各个入口，右边显示选中的内容。
竖栏从上往下依次是：检查更新、自动检查、能不能连上 GitHub、
检查助手自己的更新、推荐应用、下载加速。

「检查助手自己的更新」是助手给自己查版本用的：查项目仓库里最新发布的版本，
跟本机比一比，有新版就弹窗告诉你，点一下就下、下完点安装。
国内网络下不动 GitHub 会自动走加速通道，不会卡在那儿干等。

**推荐应用页**：单独一页，一个项目占一整行 —— 左边大图标，中间名字和简介，
右边一个按钮。列表最上面第一排是「一键安装全部」，往下按顺序一个个列。
页面从头到尾只有上下可选，左右不用管。

**工具箱页**：几个功能卡片平铺，进去各干各的。

**设置页**：分块排列，每块下面就是对应的开关或选项，选项旁边写清楚了后果是什么。

**传文件页**：先选方向（手机给电视 / 电视给手机），选完才进具体操作，
不选方向就不会看到一堆看不懂的选项。

**弹窗**：全部自己画，不用系统弹窗——电视上系统弹窗的按钮拿不到焦点，
遥控器按 OK 经常没反应。

## 怎么装

到 [Releases](https://github.com/pangtugg/easytv-partner/releases) 下载安装包，
传到电视上点开安装即可。

> 电视上装 APK 需要先在「设置 → 安全」里允许「未知来源」安装。
> 部分电视没有这个选项，可以用助手自带的
> **应用更新 → 装应用**（手机开下载页、电视浏览器访问）绕过去。

装之前可以核对一下安装包的 SHA-256，命令任选其一：

```bash
sha256sum easytv-0.1-20261025.apk
# Windows PowerShell
Get-FileHash easytv-0.1-20261025.apk -Algorithm SHA256
```

## 借鉴了哪些开源项目

本项目的**核心思路是原创的**，但在开发过程中参考并借鉴了以下开源项目的思路。
站在这些项目的肩膀上，才想清楚电视端工具该怎么做。在此一并致谢：

1. **Clean Your TV**（[@udhaykumarbala/cleanyourtv-app](https://github.com/udhaykumarbala/cleanyourtv-app)，
   原版 [@Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv)）——
   借鉴了它「电视上的垃圾清理应该怎么做」的思路：扫描安装包与缓存、按大小呈现、
   让用户自己决定删什么。本助手的「垃圾清理」模块由此而来。
2. **tv-detox**（[@Ansub/tv-detox](https://github.com/Ansub/tv-detox)）——
   借鉴了它「电视桌面应该做减法」的理念：预装能砍则砍、界面极简。
   本助手电视端 UI 的「大字、遥控友好、模块宁缺毋滥」遵循同一理念。
3. **Clash Meta for Android**（[@MetaCubeX/ClashMetaForAndroid](https://github.com/MetaCubeX/ClashMetaForAndroid)）——
   借鉴了它的订阅导入机制。本助手的「订阅助手」模块可以把订阅链接
   一键推给电视上的 Clash，保留自动更新。
4. **红果短剧 / 抖音 TV 客户端社区**（[@aston314](https://github.com/aston314)、
   [@jackherex](https://github.com/jackherex)、[@mytv-android](https://github.com/mytv-android)、
   [@markwaveio](https://github.com/markwaveio)、[@ygtec-org](https://github.com/ygtec-org)）——
   这批项目示范了电视端 App 的遥控交互范式（方向键移焦点、确认键播放、大字排版），
   本助手电视端交互向这些成熟实践看齐。

以上项目均以原许可开源，本助手**仅借鉴思路，未使用其代码**。

## 这是一个粗糙的成品，请大家多提意见

一个人业余时间写的，实话说：代码糙，有的地方逻辑绕，我回头看都想重写；
测试设备就那么几台，别的电视、盒子、国产系统上大概率有没测到的问题；
界面是我个人口味；功能取舍很主观。

**所以非常欢迎大家提 Issue 反馈问题。** 哪怕是很小的问题——
某个字看不清、某个页面退不出去、某个老电视上装不上——都请告诉我，
我看到就改。提 PR 更加欢迎，一起把它做扎实。

反馈时麻烦说清三件事：**用的什么设备**（电视/盒子型号、系统版本）、
**在哪个页面**、**当时按了什么、期望是什么**。这样基本都能复现。
